Humanoid Robot Dual-Arm Redesign

Redesign of a mobile humanoid robot to carry two 7-axis robotic arms, with the chest frame validated through an automated FEA workflow built with Claude Code.

  • AI-Assisted CAE
  • Advanced Modeling
  • CAD
  • CAE
  • Product Development

Mechanical Design

  • Adapted the mobile humanoid robot from this portfolio to carry two commercial 7-axis robotic arms.
  • Designed a new chest frame from laser-cut and bent sheet metal parts.
  • Mounted the frame on an aluminum extrusion carried by a belt-driven linear actuator.
  • Redesigned the body covers and internal parts around the new arms.

CAE Workflow with Claude Code

  • Built a Python FEA framework with Claude Code. Each part becomes one case file with geometry, materials, loads and acceptance criteria. A shared library runs the mesh, solve, checks and report.
  • I prepared the mid-surface geometry, defined the load cases and acceptance criteria, and approved each modeling decision.
  • Calculated arm loads by forward kinematics from the arm maker's robot model (URDF), for several arm poses plus a doubled dynamic case.
  • Compared four arm bracket designs with shell models and mesh convergence studies at three refinement levels, then picked the strongest one.
  • Analyzed the full chest frame with both arms and the head under four load cases, with bolts modeled as beams.
  • Every run checks itself: load equilibrium within 0.5 %, model mass against CAD, a free modal analysis for connectivity, mesh quality and contact status. The framework matched hand calculations within 3 % on four benchmark cases.
  • An independent AI review agent audits each analysis before the case closes. During setup, the agent found errors the automatic checks had missed.
  • Each case ends with an HTML report: stress, deformation, bolt loads and weld hot-spot stress.

Impact & results

  • Raised the bracket safety factor from 1.21 to 1.77 with the selected design, above the 1.5 target.
  • The chest frame met every criterion: minimum safety factor of 3.25 at nominal loads (target 1.5) and 1.66 with doubled arm loads (target 1.0).
  • Arm base rotation of 1.32 mrad at most, under the 2 mrad limit. Bolt nut loads at 24 % of catalog rating or less.
  • The full frame analysis took one day, against about two days for a single bracket before the framework.
  • Design completed and ready for prototyping.
